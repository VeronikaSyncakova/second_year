UI assembly calculator

About

Simple UI calculator with dynamic user feedback. This is a final project in a team of 2 for module where we were learning assembly programming. Every programmer needs a calculator of some form in their portfolio so we decided that ours will be written in assembly.

It is made for Motorola 86k and we used Easy 68k simulator. We made presentation and report papers to go with this project as well.

Technology

Assembly, Easy 68k simulator
