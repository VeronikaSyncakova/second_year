Forgotten night

About

Web-game that uses canvas, form for user customization, Web Storage API for consistent data storage between sessions and complies with PWA standards so the game can be installed for offline use. The game is playable on mobile thanks to the joystick and buttons.

You woke up in a strange house. You are hangover and don’t remember what you did last night or how you got here. Suddenly a magical fairy appears and helps you to remember your night.

Technology

HTML, CSS, JavaScript, Web Storage API, PWA, Json
